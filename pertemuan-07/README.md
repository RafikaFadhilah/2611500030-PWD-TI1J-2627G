# pertemuan-07

Menyalin artefak P6 sebagai dasar untuk mengerjakan dan mengembangkan tugas P7.

Menjalankan kembali website yang telah dibuat pada pertemuan sebelumnya untuk memastikan semua fitur masih berfungsi dengan baik.

Memberikan komentar pada bagian event.preventDefault(); di file script.js agar formulir dapat dikirim secara langsung ke halaman PHP.

Mencoba menggunakan superglobal $\_GET untuk mengambil data yang dimasukkan melalui formulir.

Mengubah method formulir dari GET menjadi POST untuk mengetahui perbedaan cara pengiriman data antara kedua method tersebut.

Mengamati hasil pengujian GET. Data yang dimasukkan terlihat pada URL browser sehingga parameter dapat diketahui secara langsung.

Mengamati hasil pengujian POST. Data formulir tidak ditampilkan pada URL browser karena dikirim melalui bagian request body.

Mencoba menampilkan kembali data yang telah diinput menggunakan perintah PHP agar hasil pengisian formulir dapat dilihat pada halaman website.

Menguji berbagai jenis elemen formulir, seperti input nama, email, semester, tanggal kunjungan, radio button, checkbox, select, dan textarea.

Memperbaiki bagian kode PHP agar data yang dikirim dapat ditangkap dan ditampilkan sesuai dengan nama input yang digunakan.

Memastikan halaman Beranda, Tentang Saya, dan Kontak tetap berjalan dengan baik setelah dilakukan perubahan pada kode.

Melakukan pengujian ulang dengan mengisi formulir menggunakan data yang berbeda untuk memastikan proses pengiriman dan penampilan data berjalan dengan benar.

Kesimpulan
Dari kegiatan pada pertemuan 7 ini, saya menjadi lebih memahami penggunaan superglobal PHP, khususnya $\_GET dan $\_POST. Saya juga dapat mengetahui perbedaan kedua method tersebut dalam mengirimkan data dari formulir ke halaman PHP, serta memahami cara menangkap dan menampilkan kembali data yang telah dimasukkan oleh pengguna.
