# Pertemuan 4 – CSS3 Layout dan Responsive Web Design

1. Pengembangan

- Perubahan yang dilakukan: Memperbaiki struktur HTML, merapikan kode, dan menghilangkan tanda garis miring (/) yang tidak diperlukan pada elemen kosong seperti input, img, meta, link, dan br.

- Commit dan push GitHub: Menyimpan perubahan kode dengan commit dan mengunggahnya ke repositori GitHub.

2. Pengujian

- Perangkat bergerak:
  Pengujian dilakukan menggunakan simulasi iPhone SE dengan ukuran viewport 375 × 667 piksel. Hasil pengujian menunjukkan bahwa tata letak website berhasil disesuaikan menjadi vertikal. Bagian “Selamat Datang” dan “Tentang Saya” ditampilkan secara berurutan sehingga lebih mudah dibaca pada layar kecil. Foto profil juga terlihat dengan baik. Namun, bagian bawah halaman perlu diperiksa dengan menggulir halaman untuk memastikan seluruh konten tampil dengan baik

- Desktop:
  Pengujian dilakukan pada tampilan desktop. Hasil pengujian menunjukkan bahwa bagian Selamat Datang dan Tentang Saya tersusun berdampingan. Foto profil, teks, dan daftar target belajar terlihat jelas. Secara umum, tata letak website sudah cukup baik.

- Galat dan perbaikan:

1. HTML Validator menampilkan pesan informasi tentang penggunaan tanda garis miring pada elemen kosong. Perbaikan dilakukan dengan menghapus tanda / sebelum > pada elemen seperti input, img, meta, link, dan br.
2. - Pada pengujian awal di perangkat bergerak, kedua bagian utama terlalu sempit karena masih ditampilkan berdampingan. Perbaikan dilakukan menggunakan media query CSS agar bagian “Selamat Datang” dan “Tentang Saya” tersusun vertikal pada layar kecil.

- Validasi CSS: Tidak ada kesalahan yang ditemukan pada CSS. Sudah di cek di CSS validator.
