Pada pertemuan 7, saya melakukan beberapa kegiatan, yaitu:

Menyalin artefak P6 sebagai dasar untuk mengerjakan dan mengembangkan tugas P7.
Menjalankan kembali website yang telah dibuat pada pertemuan sebelumnya untuk memastikan semua fitur masih berfungsi dengan baik.
Memberi komentar pada bagian event.preventDefault(); di file script.js agar formulir dapat dikirim secara langsung ke halaman PHP.
Mencoba menggunakan superglobal $\_GET untuk mengambil data yang dimasukkan melalui formulir.
Mengubah method formulir dari GET menjadi POST untuk melihat perbedaan cara pengiriman data antara kedua method tersebut.
Mengamati hasil pengujian GET. Data yang dimasukkan terlihat pada URL browser sehingga parameter dapat diketahui secara langsung.
Mengamati hasil pengujian POST. Data formulir tidak terlihat pada URL browser karena dikirim melalui bagian request body.
Mencoba menampilkan kembali data yang sudah diinput menggunakan perintah PHP agar hasil pengisian formulir dapat dilihat pada halaman website.
Menguji beberapa jenis elemen formulir, seperti input nama, email, semester, tanggal kunjungan, radio button, checkbox, select, dan textarea.
Memperbaiki bagian kode PHP agar data yang dikirim dapat ditangkap dan ditampilkan sesuai dengan nama input yang digunakan.
Memastikan tampilan halaman Beranda, Tentang Saya, dan Kontak tetap berjalan setelah dilakukan perubahan pada kode.
Melakukan pengujian ulang dengan mengisi formulir menggunakan data yang berbeda untuk memastikan proses pengiriman dan penampilan data berjalan dengan benar.

Dari kegiatan pertemuan 7 ini, saya menjadi lebih memahami penggunaan superglobal PHP, terutama $\_GET dan $\_POST, serta mengetahui perbedaan cara kerja kedua method tersebut dalam mengirimkan data dari formulir ke halaman PHP.
